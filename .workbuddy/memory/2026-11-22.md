## 修复云端日期全部变成部署时间
- 根因：`nuxt.config.ts` 的 `content:file:beforeParse` hook 用 `statSync(file.path).mtime` 在**构建时**注入 lastModified。本地 mtime 真实，但云端 CI checkout 后所有文件 mtime = 构建时间 → 全站显示同一部署日期。
- 方案：把真实时间**固化进 frontmatter**，随 git 走，构建时只读内容不读文件系统。
- 新增 `scripts/collect-last-modified.mjs`：遍历 `content/blog/**/*.md`（排除点目录/node_modules/assets/.obsidian），把本地 mtime 写成 frontmatter 的 `lastModified: "ISO"`。**关键：写入后用 `utimesSync` 恢复原 mtime**，否则脚本会把"运行时间"误当成修改时间，破坏幂等。已验证跑两次第二次 0 更新。
- `nuxt.config.ts`：删掉 `import { statSync }` 和时间注入代码块，hook 只保留 MathJax protect/restore。
- `package.json`：加 `collect-dates` 命令；挂到 `dev` 前（本地自动收集），**不挂 build/generate**（否则云端会重新收集、前功尽弃）。
- 已对 28 篇文章全部固化时间（原本都没有该字段）；更新 `content/blog/docs/content-authoring.md` 的 frontmatter 段落说明新机制。
- 验证：把 liquid-glass.md 的 mtime 改成 2030 模拟云端 checkout，删 content 缓存强制重解析，起 dev（跳过 collect），页面仍显示 frontmatter 固化的 2026-11-21，无 2030、无构建日 2026-11-22。决定性证明修复有效。
- 注意：`npx nuxt generate` 在本沙箱会因 safe-delete 批量删除保护（清 `.nuxt/dist`，379 文件 > 阈值 50）中断，属环境限制；改用删 sqlite 缓存 + dev 重解析验证。

## 修复灯箱关闭按钮看起来扁平
- 现象：`<LiquidGlass preset="button">` 明明在用，但看着像扁平实色饼。
- 根因：① 折射靠扭曲元素背后画面，按钮浮在 `.lightbox-overlay`（`rgba(22,16,24,0.72)` + `blur(10px)`）这片均匀深色上，没有可折射内容；② 引擎高光用 `feComposite operator=in` 拿折射后背景给高光上色，深色背景下高光也发闷；③ 44px 圆按钮半径 22，通用 `button` 预设 `edgeWidth=29` 被 clamp 到 22，整颗都是边缘带没平坦中心；④ CSS 用 `var(--glass-bg)` 实色底盖住滤镜 + `transition:all`/hover transform 触发合成层。
- 修复：新增专属预设 `iconButton`（`edgeWidth=9` 腾出平坦中心、`specularOpacity=0.75` 提亮白色高光环、`specularHardness=2.6`），按钮改用它；CSS 实色底换淡紫渐变 + 顶部高光描边，hover 旋转移到图标 `:deep(svg)`，transition 只列具体属性。button 预设共用三处不能全局改。
- 文档 liquid-glass.md 预设表加 iconButton + 一段"小图标按钮为何扁平"说明。
- 验证：11 项静态检查（误报 1 项是注释里的关键词）全通过；3005 起服务页面 200、编译无错。
