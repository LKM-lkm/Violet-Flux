# 2026-11-22 工作日志

## 修复三个回归问题（工作区未提交改动引起）

### 1. 日期显示失效（根因：JS 暂时性死区 TDZ）
- `app/pages/blog/index.vue`：`getArticleDateValue` 等 4 个日期辅助函数原来是 `const` 箭头函数，但定义在 `useAsyncData` 之后，而 `useAsyncData` 的 `.sort()` 回调在 setup 阶段就调用了它们 → `Cannot access 'getArticleDateValue' before initialization` → 整个 /blog 页 SSR 500，28 篇文章和日期全没了。
- 修复：4 个函数全部改成 `function` 声明（会提升）。验证：/blog 渲染 28 卡片 + 28 日期，无 TDZ 错误。

### 2. MathJax 渲染回归（根因：v4 并发 typeset 竞态）
- Git 记录：`dccc6ef`(10-11 "Fix MathJax markdown protection") 是好的；`d9b0d3f`(10-18) 自称修 hydration timing，但让插件在 `app:mounted` 也触发渲染，与文章页 `onMounted` 的两次调用并发 → MathJax v4 对同批节点并发 `typesetPromise()` 抛 `this.parent(...) is null`（官方 issue #3130）→ 排版整体失败。
- 修复 `app/plugins/mathjax.client.ts`：渲染队列串行化（renderQueue promise 链）、等待 `startup.promise` 后再 typeset、readyPromise 只解析一次。文章页 `[...slug].vue` 的 `onMounted` 去掉重复的 1000ms 第二次调用，只保留 nextTick 一次。
- 定界符经逐层验证是匹配的（DOM 里 `\(`，配置运行时也是 `\(`），displayMath 的 `$...$` 是为兼容 Nuxt Content 把 `$$` 序列化成单 `$`，保留。

### 3. 移动菜单没用新版液态玻璃（根因：手写 backdrop-filter 覆盖 SVG 折射）
- `app/layouts/default.vue` 的 `.mobile-nav` 模板已用 `<LiquidGlass preset="menu">`，但 scoped CSS 里手写了 `backdrop-filter: blur(22px) saturate(170%)`，把组件注入的 `url(#...)` SVG 折射滤镜盖掉了。
- 修复：去掉手写 backdrop-filter，改成 material dressing（淡紫渐变背景 + 镜面高光 + 细描边），与 index.vue 的 glass-btn 一致。暗色模式同步调整。
