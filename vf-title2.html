MathJax 数学公式

Violet Flux 通过 CDN 加载 MathJax v4，在 nuxt.config.ts 的 app.head.script 中注入全局配置，再由客户端插件在页面挂载后手动触发排版；package.json 里没有 MathJax 依赖。

当前配置

项目值
脚本地址https://cdn.jsdelivr.net/npm/mathjax@4.1.1/tex-mml-chtml.js（async，id 为 MathJax-script）
引入方式CDN，不是 npm 依赖
自动排版关闭（startup.typeset: false），由插件调用

nuxt.config.ts 中注入的配置：

TypeScript
window.MathJax = {
  loader: { load: ['[tex]/ams', '[tex]/newcommand', '[tex]/configmacros'] },
  tex: {
    packages: ['base', 'ams', 'newcommand', 'configmacros'],
    // 定界符
    inlineMath: [['\\(', '\\)']],
    displayMath: [['$$', '$$'], ['\\[', '\\]']],
    // 处理选项
    processEscapes: true,       // \$ 表示字面量美元符号
    processEnvironments: true,  // 处理 \begin{xxx}...\end{xxx}
    processRefs: true,          // 处理 \ref{...} 引用
    // 标签和编号
    tags: 'none',
    tagSide: 'right',
    tagIndent: '0.8em',
    useLabelIds: true,
    // 样式与性能限制
    mathStyle: 'TeX',
    maxBuffer: 5 * 1024,
    maxTemplateSubtitutions: 10000,
    // 错误处理
    formatError: (jax, err) => jax.formatError(err)
  },
  output: { font: 'mathjax-termes' },
  startup: { typeset: false }
}
配置项取值与作用
loader.load / tex.packages加载 ams、newcommand、configmacros 扩展
tex.inlineMath行内定界符 \(...\)
tex.displayMath块级定界符 $$...$$、\[...\]
tex.processEscapes允许 \$、\\ 等转义
tex.processEnvironments支持 \begin{...}...\end{...} 环境
tex.processRefs支持 \ref / \eqref
tex.tags'none'：公式不自动编号（可改 'ams'、'all'）
tex.tagSide / tex.tagIndent / tex.useLabelIds编号标签靠右、缩进 0.8em、用标签名作为 id
tex.mathStyleTeX 排版风格
tex.maxBuffer / tex.maxTemplateSubtitutions单个公式的规模上限（5K / 10000 次）
tex.formatError使用 MathJax 默认的错误格式化
output.font输出字体 mathjax-termes
startup.typesetfalse，MathJax 不自动排版

Nuxt 配置将这段初始化代码放在模板字符串中，因此配置源码里的 \\( 会生成浏览器实际需要的 \(。不要在这里再多加一层反斜杠，否则 MathJax 会等待错误的定界符。

渲染时机

位置行为
app/plugins/mathjax.client.ts每 100ms 等待 window.MathJax.typesetPromise 可用，最多 10 秒；调用 typesetPromise()；成功打印 MathJax rendered successfully，失败打印 MathJax rendering error:
首次加载Vue 应用完成挂载后才排版，避免在 SSR hydration 期间改写 DOM
路由变化router.afterEach 之后延迟 500ms 重新渲染
app/pages/blog/[...slug].vueonMounted 中 nextTick 调用一次，1000ms 后再调用一次

插件通过 provide 暴露 $renderMathJax。正常写文章不需要手动调用；运行时动态插入的公式可以再调一次：

TypeScript
useNuxtApp().$renderMathJax?.()

支持的语法

Markdown 与公式保护

源文件写法交给 MathJax 的文本结果
\\(x^2\\)\(x^2\)✅ 当前 Markdown 文章验证可用的行内写法
独占行 $$ ... $$Nuxt Content 输出的块公式边界✅ 当前 Markdown 文章验证可用的块级写法
\(x^2\)（源码中单反斜杠）不稳定❌ Markdown/MDC 解析可能吞掉定界符
\[ ... \] / \\[ ... \\]未验证❌ 目前不作为受支持的文章写法
$x^2$不排版❌ 未配置为行内定界符

Nuxt Content 对块公式的序列化可能将 $$...$$ 的边界归一化为单美元符号，因此 MathJax 配置同时把 $...$ 作为块级定界符处理。文章源码仍必须写成独占行的 $$...$$；不要手写单美元定界符，也不要把它用作行内公式。\\(...\\) 是唯一受支持的行内定界符。

文章中只使用表格标记为 ✅ 的两种写法。未验证的定界符不要混用；复杂公式也必须放在独占行的 $$...$$ 中。

MDC 与花括号

写法交给 MathJax 的文本说明
\(a_{i}\)\(a_{i}\)单字符下标
\(A_{ij}\)\(A_{ij}\)多字符下标
\(x^{2}\)、\(\frac{1}{2}\)原样上标和分数组合
\(\sqrt{\frac{a}{b}}\)原样嵌套花括号

编号与引用

默认 tags: 'none'，公式不会自动编号，\label / \ref 也就没有编号可用。需要编号时在 nuxt.config.ts 中把 tags 改成 'ams'（只编号带 \label 的公式）或 'all'（全部编号）：

TypeScript
tags: 'ams'

旧语法迁移

package.json 提供了迁移脚本：

Bash
npm run convert-latex   # 等价于 node scripts/convert-to-standard-latex.mjs

脚本扫描 content/**/*.md，跳过 frontmatter、行内代码与 fenced code block：

转换实现
$...$ → \\(...\\)只转换同一行的单美元定界符，生成 Markdown 中已验证可用的双反斜杠写法
独占行 $$...$$保持不变；运行时按块级公式排版

使用流程：

Bash
git status                 # 先确保工作区干净
npm run convert-latex
git diff                   # 逐个文件确认转换结果
git checkout -- content/   # 有问题时回滚

两点注意：

  1. 脚本不验证公式的数学语义，运行后务必查看 git diff。

常见问题排查

现象排查方向
公式原样显示、没有排版确认 CDN 脚本是否加载成功；控制台正常时打印 MathJax rendered successfully，出错时打印 MathJax rendering error:
等了很久仍不渲染插件最多等 10 秒，超时说明 window.MathJax 没有加载出来
公式原样显示检查 MathJax CDN 是否加载，以及文章公式是否使用受支持的定界符
$x$ 显示异常单美元只用于兼容 Nuxt Content 序列化后的块公式；源码不要手写，行内请用 \\(...\\)
\[...\] 不渲染文章中暂不支持此写法，改用独占行的 $$...$$
花括号、矩阵换行或列丢失确认内容经过 Nuxt Content 的 Markdown 解析；公式片段会在解析期间受到保护
切换文章后新公式没渲染插件在路由变化后 500ms 重新排版；动态内容可手动调用 $renderMathJax()
需要公式编号tags 当前是 'none'，改成 'ams' 或 'all'
公式字体不对output.font 当前是 mathjax-termes
